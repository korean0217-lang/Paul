# 사도 바울과의 대화게임 — 디럭스 완성판

## 포함 기능
- 업로드해 주신 바울 캐릭터 그림을 실제 게임 캐릭터로 사용
- 바울의 여러 포즈를 장면에 따라 교체
- 대화 말풍선 + 타이핑 효과
- 브라우저 음성(TTS)으로 대화 듣기
- 총 20개 선택
- 5가지 인생 경로
  1. 말씀의 교사
  2. 사람을 세우는 목회자
  3. 개척 선교사
  4. 고난의 증인
  5. 화해와 연결의 사도
- 선택 점수에 따라 경로가 달라짐
- 로마로 가는 배의 풍랑 애니메이션
- 로마 도착 엔딩
- 점수에 따라 '당신이 만든 바울의 삶' 생성
- 스마트폰/PC 반응형

## 실행
ZIP을 풀고 index.html을 클릭하면 실행됩니다.
GitHub Pages에 index.html과 assets 폴더를 그대로 올리면 웹게임으로 사용할 수 있습니다.
